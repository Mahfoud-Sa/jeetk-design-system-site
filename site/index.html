09 / GET STARTED

Build from the same foundation.

Install Flutter, apply a JEETK theme, and start composing.

Open the Flutter package ↗
import 'package:jeetk_design_system/jeetk_design_system.dart';

MaterialApp(
  theme: JeetkTheme.light,
  darkTheme: JeetkTheme.dark,
  home: JeetkPageScaffold(
    body: JeetkColumn(
      children: [
        JeetkSectionHeader(title: 'Overview'),
        JeetkButton(
          label: 'Continue',
          onPressed: () {},
        ),
      ],
    ),
  ),
);
