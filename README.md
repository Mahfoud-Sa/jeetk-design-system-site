# JEETK Design System

Bilingual design system catalogue for the JEETK Flutter package. Explore foundations, components, navigation, data display, layout, interaction states, and local-only design pattern recipes.

**Live site:** https://mahfoud-sa.github.io/jeetk-design-system-site/

The site is static, has no build dependencies, and uses local browser state for its interactive previews. The examples do not transmit information or create real accounts.

## Local preview

```powershell
cd site
python -m http.server 8000
```

Open `http://localhost:8000`. GitHub Actions publishes the `site/` directory to GitHub Pages when changes land on `main`.
