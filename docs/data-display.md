# Data display components

These widgets present records, metrics, status, and empty collections using JEETK theme and spacing tokens.

- `JeetkCard` provides the shared surface; `JeetkListTile` structures a tappable record row.
- `JeetkDataTable` wraps Flutter `DataTable` in horizontal scrolling and themed borders.
- `JeetkAvatar` shows an image or initials with an accessible label. `JeetkBadge` displays a label/count.
- `JeetkTooltip` provides a tooltip and optional tap-open rich popover.
- `JeetkAccordion` expands details; `JeetkTimeline` lays out timestamped events.
- `JeetkMiniChart` presents comparable values as accessible bars. `JeetkKpiCard` highlights a metric.
- `JeetkEmptyState` communicates an empty list or search result with optional action.
- `JeetkStatusChip` adds a semantic status label.

The example app's data display icon opens a live showcase of the components in Arabic RTL.
